        What this teaches

        In AP Computer Science Principles pseudocode, a ← b copies the value in b into a. It does not link the two variables, and it does not swap anything. Each variable holds one value at a time, and that value is the most recent one assigned.

        The tool treats each variable as a cup and each value as a sticky note. When a statement runs, the old note in the cup on the left is thrown away and a copy of the new value goes in.

        For teachers

        • Have students predict final values on paper first, then use Explore to check.
        • Load "Predict first" and ask for a vote before pressing Step.
        • In Practice, share a problem code so the whole class traces the same program.
        • Use the patterns list to see which error types came up most in a session.
        • Pair it with real cups and sticky notes. The physical version builds the model, and this tool lets students keep practicing.

        Standards alignment

        Aligned to AP Computer Science Principles Big Idea 3, learning objective AAP-1.B (determine the value of a variable as a result of an assignment), and essential knowledge AAP-1.B.3 (the value stored in a variable is the most recent value assigned).
